# نوسان‌باز PLAY

نسخه‌ی جداشده برای انتشار روی GitHub Pages؛ HTML، CSS و JavaScript در فایل‌های جدا هستند.

## فایل‌ها
- `index.html` — ساختار صفحه
- `style.css` — ظاهر و استایل
- `app.js` — منطق شبیه‌ساز

## انتشار روی GitHub
1. یک مخزن جدید در GitHub بساز.
2. هر سه فایل را در ریشه‌ی مخزن (همان صفحه‌ی اصلی مخزن) آپلود کن.
3. وارد **Settings → Pages** شو.
4. در بخش **Build and deployment**، گزینه‌ی **Deploy from a branch** را انتخاب کن.
5. شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب و Save کن.
6. بعد از چند دقیقه، آدرس سایت در همان بخش Pages نمایش داده می‌شود.

این نسخه فرانت‌اند و شبیه‌ساز مرورگری است؛ برای اجرا به Node.js، Python یا سرور نیاز ندارد. اطلاعات دمو در مرورگر کاربر ذخیره می‌شوند و بین دستگاه‌ها همگام نیستند. این پروژه به‌تنهایی بازار واقعی یا معامله‌ی مالی واقعی نیست.

برای اجرای محلی، `index.html` را باز کن یا از افزونه‌ی Live Server در VS Code استفاده کن.
