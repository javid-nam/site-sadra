# GTA: SHADOW LIFE — Browser build 1.0

A standalone top-down open-city driving sandbox made with HTML, CSS, and vanilla JavaScript.

## Run
1. Extract `GTA_SHADOW_LIFE.zip`.
2. Open `index.html` directly in a modern browser, or open the folder in VS Code and run with Live Server.
3. Click "ورود به شهر" to start.

## Controls
- Drive: WASD or arrow keys
- Handbrake: Space
- Change vehicle: E
- Enlarge minimap: M
- Pause/resume: Escape or pause button
- Mobile: on-screen controls appear on touch devices

## Features
- Large scrolling city map with roads, buildings, parks and traffic cars
- Five selectable luxury/sports cars
- Infinite-money sandbox UI; no purchases required
- Speedometer, minimap, damage and repair button
- Optional 500 m city cruise challenge
- No external JavaScript libraries and no backend required

## Honest scope
This is a lightweight **2D top-down browser sandbox**, not a full 3D GTA clone. The city and traffic are locally simulated. It has no real online services, saved account, or server-side persistence. The optional web font is decorative only; system fonts are used if offline.
